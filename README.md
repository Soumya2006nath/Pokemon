    # 🐉 Pokémon Search Web App

A simple and interactive web application that allows users to search for Pokémon by name and view their images instantly.

Built using pure frontend technologies and the public PokéAPI.

---

## 🚀 Live Features

- 🔍 Search Pokémon by name
- 🖼 Display Pokémon sprite image
- ⚡ Fetch real-time data using PokéAPI
- ❌ Error handling for invalid names
- 🎯 Clean and minimal UI

---

## 🛠 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- PokéAPI (https://pokeapi.co/)
